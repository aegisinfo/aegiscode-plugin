---
description: Show the current AEGIS account — plan, email, and cloud-memory status.
---

Call the `aegis_status` MCP tool and report the result to the user: whether the
API key is valid, the plan, the account email, and whether cloud memory is
enabled. If the tool reports no key is set, tell the user to set `AEGIS_API_KEY`
(see the plugin README) and where to get a key: https://aegiscloud.org
